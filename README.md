# Serein (restaurant website concept)

Vite + React + Tailwind CSS v4 + React Hook Form.

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/

Structure: `src/data.js` holds all copy and images, `src/sections.jsx` the page sections,
`src/Booking.jsx` the reservation form (React Hook Form validation), `src/Nav.jsx` the header and mobile drawer.
Design tokens (colours, fonts) are in the `@theme` block of `src/index.css`.
All press, suppliers, reviews, phone and email are fictional sample content.
